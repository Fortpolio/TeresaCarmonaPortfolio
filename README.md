## Deployment to GitHub Pages

### Step 1: Initialize Git Repository

```bash
git init
git add .
git commit -m "Initial commit: Maria Teresa Halili Portfolio"
```

### Step 2: Create GitHub Repository

1. Go to [GitHub](https://github.com) and sign in
2. Click the "+" icon in the top right and select "New repository"
3. Name it `TeresaCarmonaPortfolio` (or your preferred name)
4. Don't initialize with README (we already have one)
5. Click "Create repository"

### Step 3: Push to GitHub

```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/TeresaCarmonaPortfolio.git
git push -u origin main
```

### Step 4: Enable GitHub Pages

1. Go to your repository on GitHub
2. Click "Settings" tab
3. Scroll down to "Pages" in the left sidebar
4. Under "Source", select "main" branch
5. Click "Save"
6. Wait a few minutes for deployment
7. Your site will be live at: `https://YOUR_USERNAME.github.io/TeresaCarmonaPortfolio/`

## Customization

The portfolio is already customized with Maria Teresa's professional information. To make further updates:

### Update Contact Information

Edit `index.html` to update:
- Phone number
- Email address
- LinkedIn URL
- Location details

### Add Professional Photo

Replace the `.image-placeholder` div in the About section with:

```html
<img src="your-photo.jpg" alt="Maria Teresa C. Halili" class="profile-image">
```

Then add CSS:

```css
.profile-image {
    width: 250px;
    height: 250px;
    border-radius: 50%;
    object-fit: cover;
}
```

### Update Experience Details

Edit the Experience section in `index.html` to:
- Add more specific achievements
- Include additional projects or responsibilities
- Update employment dates if needed

### Update Colors

Edit the CSS variables in `styles.css` to change the color scheme:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    /* ... other colors */
}
```
